## Activity Description

This repository contains the starter files for the ELEC 4 Python Programming Flask Stack Simulator pre-demo reading activity. The activity is about understanding how HTML, CSS, Python, Flask, and Jinja work together in a web application that demonstrates stack operations (Push, Pop, Peek, and Clear).

The starter project is intentionally unfinished. The TODOs are retained for the instructor-led demonstration, as instructed.

## Original Starter Repository

https://github.com/Jackson-Soriano/f1-elec4-stack-simulator-starter

## Setup and Preview Instructions

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `templates/index.html` directly in a browser to view the static preview.
4. Click the navigation link to view the contact placeholder.
5. Review the HTML comments, TODOs in `app.py`, and TODOs in `stack_model.py`.
6. Do not complete the TODOs before the demonstration.

## Project Files

- `app.py` — Flask setup and route TODOs.
- `stack_model.py` — Stack class and stack methods.
- `templates/index.html` — Static simulator preview.
- `templates/contact.html` — Placeholder contact page.
- `templates/base.html` — Layout reference.
- `static/css/style.css` — Page styling.
- `static/js/ui.js` — Optional input-focus enhancement.
- `requirements.txt` — Flask dependency.

## Notes

The displayed stack values in the static preview are sample values. The buttons are not connected to Python stack operations yet. The instructor will demonstrate how Flask routes, form submission, Jinja templates, and Python stack operations are connected.
